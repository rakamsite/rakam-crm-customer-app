# ثبت مراجعان راکام — نسخه ویندوز

برنامه فارسی و آفلاین برای ثبت مراجعه حضوری/تلفنی، منبع آشنایی و درخواست مشتری؛ با ذخیره SQLite روی کامپیوتر و ارسال خودکار به CRM راکام.

## دریافت و اجرا

1. در [Actions → Build Windows app](https://github.com/rakamsite/rakam-crm-customer-app/actions/workflows/windows.yml)، آخرین اجرای **سبز** را باز کنید.
2. از بخش Artifacts، بسته **Rakam-Customer-App-Setup-Windows-x64** را دانلود و ZIP آن را باز کنید؛ داخل آن فقط **Rakam-Customer-App-Setup.exe** است.
3. فایل Setup را اجرا کنید. نصب برای همین حساب ویندوز انجام می‌شود و دسترسی Administrator لازم ندارد.
4. پس از نصب، برنامه را از آیکن **ثبت مراجعان راکام** روی دسکتاپ یا منوی Start باز کنید. فایل‌های داخلی در مسیر نصب نگهداری می‌شوند.
5. Windows 10/11 نسخه x64 و **Microsoft Edge WebView2 Runtime** لازم است. اگر موجود نبود، از [صفحه رسمی دانلود WebView2](https://developer.microsoft.com/microsoft-edge/webview2/#download) نصب کنید. نصب جداگانه .NET لازم نیست.

فونت **وزیر ۳۰.۱.۰** داخل برنامه همراه مجوز OFL قرار دارد؛ به اینترنت یا نصب فونت در ویندوز وابسته نیست.

به‌روزرسانی با اجرای نصاب جدید روی همان حساب و همان مسیر نصب انجام می‌شود. دیتابیس، صف ارسال، اتصال و پشتیبان‌ها در مسیر مستقل `%LOCALAPPDATA%\Rakam\CustomerApp` باقی می‌مانند؛ حذف برنامه هم این اطلاعات را حذف نمی‌کند. نسخه قبلی را پیش از نصب ببندید و نسخه جدید را با همان حساب ویندوز اجرا کنید.

برای استفاده پرتابل، بسته **Rakam-Customer-App-Windows-x64** همچنان موجود است؛ در این حالت همه فایل‌های پوشه باید کنار هم بمانند.

این نسخه امضای تجاری ندارد و ممکن است Windows SmartScreen نام ناشر را ناشناخته نشان دهد. فقط بسته ساخته‌شده از همین مخزن و اجرای موفق را استفاده کنید.

## اتصال به CRM

ابتدا تغییرات سرور در شاخه `new` مخزن `rakamsite/rakam-crm` همراه migration نصب شود؛ برنامه بدون آن هم آفلاین کار می‌کند، اما همگام‌سازی ندارد.

1. با حساب خود کارشناس وارد CRM شوید.
2. «تنظیمات ← ثبت مراجعان و برنامه ویندوز» یا آدرس `/customer-app` را باز کنید.
3. نام دستگاه را بنویسید و کلید بسازید؛ فقط همان لحظه نمایش داده می‌شود.
4. در برنامه، «اتصال و پشتیبان»، آدرس ریشه مثل `https://crm.safaeico.com` و کلید را وارد کنید.
5. «بررسی و ذخیره اتصال» را بزنید. کلید در ویندوز با DPAPI حساب جاری محافظت می‌شود و به رابط بازگردانده نمی‌شود.

کلید برای ۹۰ روز معتبر است؛ تمدید با کلید جدید همان حساب و همان دامنه انجام می‌شود. دستگاه از CRM قابل لغو است. لغو، دسترسی آینده را قطع می‌کند و داده آفلاین قبلی را از راه دور پاک نمی‌کند.

## کار روزانه

- مراجعه جدید را ثبت کنید؛ ثبت ابتدا محلی است و به اتصال وابسته نیست.
- نام، شماره، منبع آشنایی، روش این مراجعه، نیاز و یادداشت جدا ثبت می‌شوند.
- بدون موبایل هم مراجعه ثبت می‌شود؛ مخاطب و سرنخ CRM ساخته نمی‌شود.
- با انتخاب «سرنخ پیگیری»، موبایل الزامی و سرنخ به نام همان کارشناس ساخته می‌شود.
- تاریخ پیگیری شمسی با قالب `۱۴۰۵/۰۷/۲۸` است؛ ساعت ۹ صبح تهران ثبت می‌شود.
- فیلدهای تکمیلی و الزامی مخاطب از تنظیمات همان CRM دریافت می‌شوند.
- همگام‌سازی در شروع، بعد از ثبت و هر ۶۰ ثانیه تلاش می‌شود. خاموش یا بسته بودن برنامه به معنی عدم ارسال تا اجرای بعدی است.
- شماره موجود به همان پرونده مجاز متصل می‌شود؛ مشخصات قبلی مخاطب بازنویسی نمی‌شوند.
- ثبت‌های ردشده با پیام اعتبارسنجی در سوابق قابل اصلاح‌اند. رکورد منتظر ارسال یا همگام‌شده تغییر نمی‌کند، چون ممکن است سرور قبلاً آن را پذیرفته باشد؛ برای تعامل بعدی «مراجعه جدید» بزنید.
- خروجی CSV فارسی دارای BOM است؛ گرفتن خروجی، وضعیت «همگام‌شده» ایجاد نمی‌کند.

## پشتیبان

اطلاعات در `%LOCALAPPDATA%\Rakam\CustomerApp\customers.db` ذخیره می‌شود. در شروع هر روز پشتیبان SQLite سازگار با WAL گرفته و ۱۴ نسخه آخر نگهداری می‌شود. از «ذخیره پشتیبان» برای کپی در دیسک یا پوشه دیگری استفاده کنید.

«بازیابی» پس از تأیید، اطلاعات فعلی را جایگزین می‌کند؛ پیش از آن نسخه ایمنی می‌سازد. پشتیبان شامل کلید اتصال نیست. بعد از انتقال به ویندوز دیگر، کلید جدید **همان حساب CRM** را وارد کنید.

دیتابیس مشتریان رمزگذاری کامل نشده است؛ از حساب ویندوز اختصاصی، قفل صفحه و دسترسی محدود به پوشه/پشتیبان استفاده کنید. یک فضای محلی به یک حساب و دامنه CRM متصل می‌شود تا داده شرکت‌ها مخلوط نشود.

## مرز نسخه اول

- دریافت کامل مخاطبان مجاز به صورت صفحه‌بندی؛ جایگزینی کش فقط پس از دریافت موفق همه صفحات.
- ارسال افزایشی و تکرارپذیر مراجعات با UUID ثابت؛ تراکنش سرور و رسید ثبت.
- مشتریان و مراجعات جدید سایر دستگاه‌ها از مسیر مخاطبان به‌روز می‌شوند؛ **تاریخچه مراجعات این برنامه فقط سوابق همین دستگاه است**. تاریخچه مشترک در CRM دیده می‌شود.
- ویرایش دوطرفه مشخصات مشتری، فایل‌ها، چت‌ها، تغییر مسئول و Pipeline در این نسخه نیست.
- اطلاعات بین دستگاه‌های آفلاین تا اتصال مشترک نمی‌شود.
- انتساب «منبع آشنایی این مراجعه» با «روش مراجعه» جداست؛ موتور انتساب چندلمسی و گزارش درآمد کانال‌ها نیست.
- deploy سرور، اتصال واقعی و QA روی ویندوز اپراتور جدا از build/تست خودکار هستند.

## توسعه

نیازمند .NET SDK 10؛ رابط HTML/CSS/JS محلی با WebView2، Core مستقل و SQLite. هیچ سرور محلی، Electron یا سرویس پولی لازم نیست.

```powershell
dotnet run --project tests/Rakam.CustomerApp.Tests -c Release
dotnet build src/Rakam.CustomerApp.Windows -c Release
dotnet publish src/Rakam.CustomerApp.Windows -c Release -r win-x64 --self-contained true -o dist/Rakam-Customer-App
```

قرارداد سرور: `docs/CUSTOMER-APP-SYNC.md` در ریپو CRM. کلید، دیتابیس مشتری و پشتیبان را وارد Git نکنید.
